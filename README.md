## 💡 Sobre o projeto

Um cardápio digital moderno e responsivo para a **Durrr Burger** — a lendária hamburgueria do universo de Fortnite, agora no mundo real (ou quase)!

O projeto oferece uma experiência fluida e organizada para os clientes visualizarem hambúrgueres, combos, acompanhamentos, bebidas e sobremesas de forma atraente e intuitiva.

---

## ✨ Funcionalidades

- 🍔 Visualização completa do cardápio por categorias
- 🥤 Seções dedicadas para hambúrgueres, combos, acompanhamentos, bebidas e sobremesas
- 📱 Layout responsivo para desktop e mobile
- 🎨 Design temático inspirado no universo de Fortnite

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/Cardapio-Hamburgueria.git
```

2. Acesse a pasta do projeto:
```bash
cd Cardapio-Hamburgueria
```

3. Abra o arquivo `index.html` no seu navegador — ou use a extensão **Live Server** no VS Code para uma melhor experiência.
